# Modèles livrés avec l'application

Déposez ici un fichier `sender-sauvegarde.json` (obtenu avec **Réglages → Sauvegarde des modèles → Exporter**)
pour que l'application installée démarre avec ces modèles, identités et images.

Ils ne sont importés qu'au premier lancement, quand l'application n'a encore aucun modèle :
rien n'est écrasé chez quelqu'un qui l'utilise déjà.
